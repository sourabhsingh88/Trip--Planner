MAVAN ------ Apache Maven is an open-source tool that helps build, manage, and publish Java projects.


working ---- 1.Uses the Project Object Model (POM)
			 2.Automatically downloads project JARs, libraries, and other files
			 3.Integrates with source control systems like Git
			 4.Promotes the use of a centralized repository for JARs and other dependencies
			 
			 
Uses ------- 1.Build Automation ----- Automatically compiles source code, manages dependencies, and assembles binary codes into packages 
			 2.Project management --- Handles team collaboration, reporting, documentation, distribution publication, and release managemen
			 3.Project information -- Provides quality project information, including regular reporting on the project's development status 

POM --- It is a xml file which contains information about project(structure) and its configuration

07 - run jar file on cmd	
			1.add code in pom file according to your package.
					<build>
						<plugins>
							<plugin>
								<groupId>org.apache.maven.plugins</groupId>
								<artifactId>maven-jar-plugin</artifactId>
								<version>3.3.0</version>
								<configuration>
									<archive>
										<manifest>
											<mainClass>com.amstech.collage.erp.test.impl.Main</mainClass>
										</manifest>
									</archive>
								</configuration>
							</plugin>
						</plugins>
					</build>
					
			  2.now again create jar file
					"mvn clean package"
					
			  3.go on target directory
					"cd target"
					
			  4.run jar
					"java -jar collage-erp-0.0.1-SNAPSHOT.jar"
